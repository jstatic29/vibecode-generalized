# Second-industry pilot findings

Assessment of the Weston environmental/infrastructure services pilot,
2026-11-11. Website/audience context informed an illustrative proposal-evidence
scenario, not claims about the company's actual systems or business problems.
This sanitized summary contains no resource IDs or private execution scripts.

## What the evidence supports

The selected model used existing declarative recipes without engine changes:
14 planned Delta tables including governance and 206 planned physical rows
including raw copies. Full raw/physical-work reconciliation was not independently
performed. A durable data build and saved SQL checks reconciled 30 relationships,
12 scenario keys and 106 grouped/period/quarter rows.

Headlines reconciled: 12 projects, 24 evidence links, 15 links needing review,
and actual-minus-planned cost variance of 15,165,936 integer cents.
Native ontology readback covered eight entities and source annotations; the
operator reported correct bindings without property reselection. Bounded SQL-only
agent samples passed; after ontology attachment, two SDK scalar questions matched
baselines and passed the critic. Their traces showed ontology context and
lakehouse SQL, not proof of graph traversal.

The measured session-window delta was **383.759269950 Copilot AI credits**:
385.137062100 minus 1.377792150, from 16:26:26 to 21:52:49 UTC on 2026-11-11.
The conversation was reused; pre-baseline setup and later replies are excluded.
This is not whole-pilot cost, a cash estimate or a credit-budget recommendation.
Fabric CU consumption and active-work timing were not measured.

## What remains unaccepted

Presenter independence was not assessed. The operator explicitly skipped graph
execution; no pilot graph parity/traversal acceptance exists. Post-attachment
dimensional, ratio, refusal and repeated coverage, independent viewer access,
full final table/column/exclusion acceptance and durable SDK evaluation remain
unverified. The IQ and rehearsal gates remain
pending. Semantic model, Planning and app were excluded.

The evaluation session was still `InProgress` at its last saved status, not
necessarily now. Its owner must check current status and separately approve
shutdown or further work. No cancellation or new execution was performed as part
of integrating these learnings.

## Incorporated lessons

- Resume regional notebook-create operation Locations on the canonical Fabric
  API host using the **same operation ID**; never send credentials to regional
  hosts or retry creation. Narrow URL validation and recovery tests cover this.
- [Inspect native bindings first](ontology-bindings.md), repair unresolved
  mappings only, and preserve the observed partition metadata without claiming
  a universal binding fix.
- Use the approved direct [GraphModel query API](graph-query-handoff.md);
  an ontology-agent tool restriction is not a platform-wide graph-query limit.
  Missing/conflicting specialist support still requires an explicitly approved
  reviewed public-API route, not a silent fallback.
- [Guard SDK outputs in their actual namespace](data-agent-evaluation.md).
  Preserve the failed durable job and successful interactive sample as separate
  evidence; prepare a pinned, reviewed dependency path before another approved run.
- Preserve a manifest-backed private handoff outside session storage. The
  package's relative index maps historical references, lists omissions and keeps
  machine evidence distinct from operator attestation. Do not clone its state
  into a new customer's run.

This is useful second-industry learning, not an independent end-to-end presenter
benchmark. A fresh presenter/conversation with bounded approved graph and
post-ontology checks is still required by the [pilot guide](presenter-pilot.md).
